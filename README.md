# 🚛 Sistema de Gestão para Agência de Pneus

Sistema web desenvolvido para auxiliar na gestão operacional e administrativa de uma agência de pneus, centralizando processos como controle de estoque, atendimentos, fornecedores, serviços e custos operacionais.

## 📋 Sobre o Projeto

O objetivo deste projeto é fornecer uma plataforma que permita gerenciar de forma eficiente as operações diárias da empresa, facilitando o acompanhamento de indicadores e a tomada de decisões através de dashboards e relatórios.

O sistema está sendo desenvolvido como parte do meu processo de aprendizado e evolução profissional, aplicando conhecimentos adquiridos no curso técnico de Desenvolvimento de Sistemas (ETEC) e na graduação em Engenharia de Software (FIAP).

develop

## ✨ Funcionalidades

* Autenticação de usuários
* Cadastro e gerenciamento de funcionários
* Cadastro de serviços
* Controle de atendimentos
* Controle de estoque de pneus
* Movimentação de compras e vendas
* Cadastro de fornecedores
* Controle de custos fixos
* Controle de custos por serviço
* Dashboard administrativo
* Relatórios gerenciais

## 🗄 Estrutura do Banco de Dados

O banco de dados foi modelado para atender às necessidades de gestão da agência, contemplando:

* Funcionários

* Pneus
* Movimentações de estoque
* Fornecedores
* Compras
